# Music Codigos

Pequenos scripts em Python que exibem trechos de músicas animados no terminal usando a biblioteca `rich`.

## O que tem aqui

- `damas.py` — anima letra com ritmo e cores
- `lisboa.py` — mostra um trecho de música com efeito de digitação
- `olhos.py` — apresenta versos com pausa e destaque visual
- `sol_e_a_lua.py` — exibe poesia em terminal com animação de texto

## Requisitos

- Python 3.8+
- Biblioteca `rich`

## Instalação

```bash
pip install rich
```

## Como usar

```bash
python damas.py
python lisboa.py
python olhos.py
python sol_e_a_lua.py
```

## Descrição

Cada script imprime uma letra de música no terminal letra por letra, com cores, pausas e um visual tipo "máquina de escrever". É útil como demonstração de animações de texto simples em Python.

## Observações

- Funciona no Windows, Linux e macOS
- Se quiser, adapte as frases e os tempos para criar sua própria versão
